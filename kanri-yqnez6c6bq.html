管理者の設定

GitHub の鍵を、管理者パスワードと部員用パスワードでそれぞれ暗号化して保存します。部員は部員用パスワードで 部員用ページ に、管理者は管理者パスワードでこのページに入れます。

  1. GitHub にログインした状態で 鍵の発行ページ（Classic） を開く
  2. Note に card、Expiration（有効期限）を選ぶ
  3. Select scopes で public_repo だけにチェック
  4. Generate token を押し、表示された鍵（ghp_で始まる文字）をコピーして下に貼る

部員用パスワードがすでに決まっている場合、空欄のままなら今のパスワードがそのまま使えます。管理者パスワードとは別のものにしてください。

⚠ まだ管理者パスワードが決まっていません。下の「設定」から管理者パスワードを決めてください。
